glinet-dropbear

Dropbear SSH @VERSION@ for GL.iNet routers, built with OpenWrt's patches and options: ECDSA and FIDO/sk- keys enabled, static, for aarch64, ARMv7, MIPS and MIPSel. It runs in place of the firmware's Dropbear and rolls back automatically if the new server does not come up. Source and build details: DigitalCyberSoft/glinet-dropbear-feed.

Install (on the router, as root)

curl -fsSL https://digitalcybersoft.github.io/glinet-dropbear-feed/setup.sh -o /tmp/setup.sh
sh /tmp/setup.sh --dry-run
sh /tmp/setup.sh

This feed is signed. The installer trusts only the key with fingerprint @FINGERPRINT@ (feed.pub), and opkg checks every update against it. No --force-signature is involved.

Undo

opkg remove glinet-dropbear

This restores the firmware's own Dropbear binary. A firmware upgrade does the same.
